# SOC 2 Policy Gap Review

A reusable Codex skill for reviewing startup access-control policies against a
practical SOC 2 access-control crosswalk. It returns evidence-grounded gaps in
a fixed Markdown format and includes ten expected-findings evaluation fixtures.

## Contents

- `soc2-policy-gap-review/` — the installable skill, crosswalk, and UI metadata
- `evals/` — ten short policy fixtures, expected findings, and a structural validator
- `NOTES.md` — observed failure modes and the design changes that addressed them

The project source is also provided as `soc2-policy-gap-review-source.zip` for
one-click download while retaining the exact folder structure required by the
skill.
